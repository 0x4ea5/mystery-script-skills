# 输入、产物与下游移交

约定描述信息含义，不强制项目采用特定目录、文件名、Markdown/JSON格式或字段拼写。已有索引、数据库或清单能表达同样信息就沿用。

## 输入

- 获准处理的源文件及其版本归属：PDF、扫描/照片、文档、独立卡、补扫或正式勘误。
- 项目根索引、来源清单、阅读权限、已有页映射和断点状态；缺少时在本次授权范围内盘点建立，不自动搜索未授权材料。
- 用户要求的深度与完成范围：提取、OCR初稿、选页校订或全量看图校订。没有全量校订要求时按用途合理选择并准确标状态，不以产物存在代替校订。

工具可以替换；缺OCR或渲染环境时保留原件和已完成部分，说明未完成环节，不把未经识别的内容当成空白或校订稿。

## 产物契约

| 层 | 至少能回查的信息 |
| --- | --- |
| 原件清单 | 稳定源ID、来源/版本、原件路径、SHA-256、实际页数/定位类型；不完整或损坏状态 |
| 页/子单元清单 | 稳定ID、源ID与哈希、物理页/原始段落、印刷页（可未知）、父页/裁切位置、原图及原始OCR入口 |
| 原始识别 | 提取文字或OCR全文、文字框坐标、坐标所依附的图像尺寸、置信度（不可用则缺失）、引擎与处理配置 |
| 可维护正文 | 逐页或单元锚点、正文、原图与OCR回链、采用版本、实际校订范围与状态 |
| 校订与疑点 | 修改前后、依据及原图位置、确认程度；遮挡/疑字、缺页、失败页与未证实映射 |
| 阅读/来源映射 | 逻辑顺序与原物理定位的关联、独立补扫来源、重复/异文关系；不改写原档顺序 |
| 续做状态 | 各处理环节已完成范围、缓存配置与产物哈希、未完成原因、下一位置 |

原始文字与解释分开。需要去除排版的正文视图时，保留能追溯到完整页的关系与删除依据；任务、停止标识、角色要求和批注在归档中保全，可作为结构字段，不由OCR阶段决定下游是否朗读或执行。

## 交给打本/解析阶段

提供一个明确入口，并随交付列明：

1. **当前使用哪版**：源ID/哈希、正文入口、页码规则和已确认的逻辑阅读映射；历史版本仍在哪里。
2. **哪些可以作为文字依据**：已实际看图的单元与范围、初稿部分、仍需看图的复杂版面；校订状态不等于剧情已经解释。
3. **哪些尚未确定**：缺/重页、遮挡、疑字、异文及未确认对应，附回查位置。下游不能把这些自动当作确定事实。
4. **如何安全复用单元**：独立卡/限定片段的入口和边界检查状态；完整归档与受限单元的来源关系存放在哪里。沿用明确的访问限制，不自行指定角色分配或发放时间。
5. **如何继续**：尚待处理的源文件/页与失败原因、可复用缓存及会使其失效的配置变化。

可以使用清单、索引、校订正文、图像与疑点表的组合，不强制制作重复副本。只有被明确要求的阶段才继续开展；OCR交付本身不自动启动人物关系解析、DM带本、玩家模拟或语音制作。
