# 分角色运行与信息边界

## 实例与材料

DM可读当前主持资料及全剧本。玩家以空白上下文启动，支持时用 fork_turns="none"，只给行为规则和中性玩家区的明确允许文件；不继承根历史、旧桌发言、答案和主持目录。正常续局唤醒原实例，新开一桌才建立新玩家。

并发小于角色数就分批运行同一组身份。实例丢失时只按当时已知范围重建并记录，不补写“先前真实发言”。工具不支持独立实例时可继续资料准备，不能声称已实际模拟；全知编写的对白只能是授权虚构改编。

按已核主持顺序发本，物理相邻页不等于印刷页连续，乱序/漏页/不同角色停止页分别映射。共同文本核为同一场景后才共用，不把某视角的“你”无说明地套给全桌。

每包核正文、页图、停止点和关键段非空。不能盲删首行当标题；原件图文、邻卡、答案元数据不能串入包。原卡文字忠实，口语改写只在讨论/音频层。准备好不等于已发，私读完也不等于全文已公开。

发放账记阶段、接收者、版本/哈希、物理页与印刷页、允许公开范围、派发事件及回执。准备/派发/收到/公开分别记录；补记带说明。漏发或实质误读正式补发，原首答和真实更正保留，不在剪辑里静默改成从未发生。

## 讨论与主持

独立观察/分享齐后统一公开，后续围绕有效疑点交错接话，不要求全员轮流长报告。玩家可指出希望谁回应；未知保留，不索取隐藏思维过程。只记录可观察的发言、依据与结论。

原作演绎照指定台词/动作执行，无台词者不补台词；明确这不是玩家自由反馈。发下一段前核阅读门槛，结局原作独白与读后自由意见分别收取，不要求全员同一种情感评价。

主持先看真实讨论，再决定等待、定位原句、提示或裁定。有效推理期间不代总结/代答；停滞先分清缺资料、没找到原句、规则歧义或实质分歧。提示账存原句、接收者、级别、新前提与随后回应，提示后命中不倒记首解。

按卡面与本阶段规则验收，至少一位真实玩家复核关键动作链。接受等价措辞及满足已发约束的其他方案，保留未排除变体。手册设定不冒称已公开物证；缺不在场不等于有罪，未证明唯一/最短就不这样称。新增主持补足先明示再使用，不暗改题面。

门槛完成后可开放已发原文共查并记时间/范围，不自动公开所有私本，也不倒记为从一开始可见。程序性同意可批量逐项收，但仍须每人的真实表态；关键新结果后的推理不能预演。

## 认知与冻结

稳定内部ID关联实例、声线和来源，逐发言显示名独立保存。本人公开自认才更新，声明句之后生效；私有回执或他人的称呼不提前触发。以后修正只影响新发言，不重命名旧事件/字幕，同名候选用座位辅助区分。

每幕冻结发放账、对白、提示/裁定、阶段身份板和未决问题。音频只承接已发生范围，后期整理不补成全桌同意或已经阅读结局。秘密材料按真实公开门槛安排。

实体加热、磁吸、音乐、摆位仅用图文替代时说明实际范围；事后答案图只算复盘图。终局未到就存准确停点，不为剪辑流畅编造成功。
