# 模拟日志转广播剧

实际模拟或明确标注的虚构对白完成后，使用已安装的 `$local-dialogue-audio`。通过当前技能目录定位并读其 `SKILL.md`，渲染时再读 `references/pipeline.md` 和运行环境说明。两技能分别发现/安装，迁移可用包含两者的整套技能ZIP。配音技能缺失时先完成对白和交接清单，寻找已有等效流程，不捏造工具或把文本称已出音频。

交接以下内容：

- 当前来源版本、模拟日志入口、实际完成的幕与阅读门槛，虚构或缺失的部分。
- 各幕发放顺序、认知边界、首答/错误/提示/修正/验收，主持补足及待核项。
- 范围为讨论改编、材料全文或混合；阅读节点是否以静音说明跳过。讨论版不称整套逐字有声书。
- 固定说话人ID与声音映射、逐发言历史显示名及本人公开更名事件；默认复用已认可参考声音，不随角色认知或字幕称呼改声线。人数与声音依本次配置，不每幕重设计。
- 分章/分段清单、对白、每段类型与来源、未配读注记、输出位置及既有缓存状态。读本、原作演绎、实际讨论、制作说明先有来源类型，再明确哪些随读本开关过滤，不凭章标题猜。

续做“读本＋讨论”版时保留现有讨论版。逐页对照原图校订拟朗读正文，按实际发放与停止点插入，不能只拼原始OCR；不同个人视角保留，同源共景与剧场列覆盖记录。已有演绎逐字覆盖的台词复用原句，只补缺失的旁白或台词，避免全文读后马上再演一遍。未公开的角色秘密与私人操作指令放在本人真实公开之后，或明确命名的终局后附录；新增朗读与制作过门不冒充当时的玩家发言。

先核故事顺序，再编同题穿插接话：分享线索、追问、反例、复算、改口、DM转场。不按六个文件顺序依次朗读，不将终局知识提前塞入初期推理，保留关键错误与提示成本。

已认可声音并授权整套就复用续做；确实需要新声线时先产短试听。GPU合成、分句缓存、异常句重试、音量、MP3/SRT及播放器由配音技能负责，不重复实现另一套。清单 `reviewed: true` 表示agent已核信息顺序，不是新增用户审批。

稳定公开的片段也可先冻结交给配音，例如“新材料分享与六人独立初解”，不必等整幕验收。明确片段边界、实际公开来源和未完成任务，后续讨论另章；不得为填满配音队列提前公开未收齐的独立答案，也不能把初解片段标成整局完成。实际模拟、源稿编辑与已审片段合成可并行，演员继续沿用原实例与当前认知。

声音质量靠实际试听；语义顺序靠来源和发放账；文件完整性靠解码、时长、字幕、链接及ZIP校验，分别记录范围。默认交付分章/分段MP3及LRC/SRT、稿件和播放器，读本与讨论独立可寻址；混合章按真实边界拆，复选框去读本后仍保持全部讨论原序。连续版按需保留或新增，旧无读本版不覆盖，不强制将各版本重复塞进一个ZIP。GPU并发由配音技能按实测资源/吞吐调度，模拟技能不限定一个进程。
