# 从原文到可带本资料

使用能回查原图的当前归档。先读主持流程及勘误，建“阶段—发放材料—认知边界”索引，再精读本阶段材料。问题库用于查漏，不代替通读与实操。

## 证据与版本

关键结论记录类型、来源、位置和有效阶段：

| 类型 | 记录方式 |
| --- | --- |
| 原文明文 | 文件、版本、PDF物理页／Word原始段落；疑点回看原图 |
| DM手册解析 | 标主持解析，不伪装成玩家原文已公开事实 |
| 补充与勘误 | 原句、修正、出处、生效范围；可选玩法另标 |
| 推论 | 前提与尚未排除的反例，不称原文明文 |
| 主持补足 | 本次采用的额外定义，说明补足前的歧义 |
| 待核验 | 缺页、模糊图处、仍可成立的解释 |

手册选全文或分章之一检索，OCR与校订稿不算独立证据。追溯旧结论时才读旧档，核对新版是否保留对应句并重新定位。

## 每幕整理到能实际带

- **准备**：物料、玩家分配、设备与场景，哪些只能文字模拟。
- **开场与发放**：引入、发给谁、发什么、先读还是先讨论、不得提前透露什么。
- **当前问题**：玩家要完成的任务、已有规则、可见关系图及应回查的原页。
- **推进**：讨论方向、常见错误、可接受变体；按实际卡点提示，不要求复现标准答案措辞。
- **提示**：轻提示、指向材料、局部示例、主持补足的区别，何时使用、怎样计成本。
- **操作与验收**：板书、摆放、动作复算、成立约束及分歧处理。
- **转场**：当前暂定结论、未揭示真相、下一份材料何时发及对应来源。

“看完能带”需要主持具体说什么、观察什么、操作什么，不能只交剧情摘要。

## 人物与板书

分阶段呈现当前身份认知、原文作者/角色对应、已知关系、故事摘要和来源。保留早期误认，终局不能反写前期卡片。家族、性别、身体、意识、姓名标签按原文明示区分，不凭配音性别或图上邻近推断。

先交可离线打开、可编辑的本地入口与备份包。用户要求外部白板时沿用指定服务及其工具/技能；本地制作不自动授权外部消息。当前板只显示一题、必要规则、当前图和来源，长证明放复盘层。

区分开题前题面/空白板、讨论中板书和验收后答案板。事后补图标复盘/重建，不能说玩家首解时已看过。剧情幕名与主持操作轮次分别标。

给续读入口：读到哪里、哪里不懂、下一份完整材料/一幕/一组要做什么。不把每页拆独立学习任务，不以刷题取代材料理解。
