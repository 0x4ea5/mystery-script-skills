# 观众向实际讨论

关键问题留足真实互动：分享、追问、不同解释、反例、验证、改口和残余疑问。三至五轮可作节奏参考，不强制轮数、解释数或错误数；小问题自然结束，有效分歧就继续。短句接具体同桌，避免六篇报告轮播或机械“结论、两条依据、一个未知”。

主持只说必要原作场景、规则、发放和裁定。等候可在音频剪去，不能因此向玩家灌输无记录答案。允许隐瞒、怀疑、误判、自责和不同意，不预设谁必须答错或感动，不把主持解释当共同接受。

新物件、照片、图示或空间约束，由当时知道的人自然讲清可见要点，让关键指代可听懂。实质新信息/推理回交实例实际发生，再进入音频；承接不能新增原材料未说的行动、责任或确定性。

称呼采用本局选择的昵称或动态认知。昵称标清玩家身份；动态名存本人公开声明、生效句与确定性，内部座位/声线不变。标题、文件名、目录、播放器也按旁听顺序检查剧透，不以终局名改前期内容。

音频保留错误→质疑→复算→改口的因果链。合并重复只改音频层，原提交/公开记录不改；制作误读与推理错误分开，不把“怀疑”改成“承认”，不把比喻当亲历动作。

独立首答高度重合时，可保留一份完整的分组或名单，再保留其他人各自不同的对照、假说、反例与疑问，避免六份同内容报告连播。只在尚未冻结的音频稿中逐段删节，记录原句、出处与原因，备份完整稿；不得补写“全员同意”等未实际说出的总结，也不得剪掉影响结论的分歧。

读本是模拟输入，用户可选讨论音频或读本加讨论。朗读须用看图核过的正文，按真实停止点及秘密公开门槛穿插；共同演绎同源内容呈现一次。移交段类型和来源，配音阶段据此制作可过滤播放段，不为后期拼造玩家台词。

AI轮次不换算真人时长、成功率或沉浸感；技术核验与实际试听范围分别报告。
