# 来源、编排与动态称呼

## 本阶段输入与记录层

接收现有对白/模拟记录、实际发放账、允许朗读的已校订材料、采用的版本及固定声线配置。缺少的来源、发放门槛或校订状态标待核；先完成不受影响的部分，不凭后文补造经过。转语音不自动授权运行玩家实例、解析全剧透或补写结局。

逐发言至少能回查：

| 信息 | 用途 |
| --- | --- |
| 稳定turn ID、原始序号 | 与原稿及各版顺序比较；分段或改显示名不换声线身份 |
| 内部speaker ID、固定参考声音 | 合成与缓存；不因人物姓名、性别或暂认身份变化而更换 |
| 原文、源文件/版本/哈希及行/字符区间 | 区分逐字沿用、截取、改写和新写；标题、来源、操作说明不混入配音 |
| 历史显示名、该发言时生效的显示名与认知状态 | 保留原记录称呼，同时生成观众在此刻应看到的字幕 |
| 内容性质与所属segment ID/type | 区分玩家自由发言、主持发言、原作演绎、原文朗读及授权编辑补充 |
| 发放/公开门槛、前后turn锚点 | 证明读本和秘密片段未提前出现，并能接回实际讨论 |

名称与文件名按项目选择，字段表达同等含义即可。类型不是姓名真伪判断：原作演绎不能冒称自主推理，实际玩家的错误结论也不能被编辑改成正确台词。

## 依真实信息门槛插入

- 阅读顺序以实际发放、同桌公开与阶段裁定为依据，手册提供规范参考；文件名、修改时间、最终答案不是实际发放账。材料授权和角色当时可知范围分别核对。
- 读本段落放在对应实际发放之后、玩家对此材料的真实反馈之前。原本私密的内容要等实际公开或明确设定的终局后附录，不能只因制作人已读到就提前播；附录不冒称当时公开。
- 给插入位置保存前后原句/turn ID。剧场收尾与新读本共用一个旧发言间隙时，先收完前场的台词/动作，再过新阅读门槛；仅满足“在两句之间”不足以证明场景顺序正确。
- 需要冻结已有讨论时，保存实际原始发言集合的ID、speaker、文字与顺序，验证它在整合版中是完全相同的有序子序列。数量从本项目基线计算，不写死历史项目段数。用户另行授权删改时，保留原稿并提供逐项改动记录，不仍声称原句未改。
- 保留反例、错误、犹豫、互问、提示、修正与各人的最终感受；某个人总结不等于全桌同意，提示后判断不倒写成独立首解。整理围绕真实问题的接话，不强行凑全员长报告或伪造回答。

## 同源朗读与原作演绎

原作共同剧场与玩家实际演绎逐段比对。已经演出的内容由原演绎覆盖，缺失的必要台词/动作可在原位置补入；不要先完整读本，再完整演同一场。归属按实际角色槽位，不按声音性别猜人物。

同一公共场景出现在多人本中时，可选择一个明确版本共读一次；每个人独有视角保留。留存来源片段→朗读/演绎/未配元数据的覆盖映射。不同人称、字面异文或原作先后冲突要注明采用版本及差异，不说成逐字相同，也不为去重而删掉实质不同的信息。读本正文覆盖和实际讨论覆盖分别核验。

## 按本人公开认知变更显示名

内部speaker ID始终固定。公开自认前使用中性玩家名；别人称呼、关系猜测、私记姓名或制作人知道的真名，不触发字幕改名。

- 姓名事件引用本人实际公开原句。声明句仍用此前显示名，完整句结束后，后续本人发言才使用新认知；长发言含多个完整句时可以在句间切换，不能在声明尚未说完时先贴新名。
- 支持部分认知：只认名字、姓未定、姓氏候选、完整暂认名、当期验证、后来改口各自记录。不要把“可能姓某”直接补成全名，或把阶段验证写成终局真名。
- 验证时暂填的试名、本人公开自认与主持反馈分别记录。仅报一个试名不自动升级显示名或记成恢复记忆；整体结果不能定位到个人对错时，不把某个人标成已经验对。全对或全错若可由总数直接推出，记录此依据，仍不把临时试名硬充为本人认同。
- 新认知可推翻旧认知，但不回填已经播过的发言、先前章节、目录或历史显示名。真名/施咒者等未公开身份也不提前放进前置标题、文件展示名或播放器目录。
- 固定声线模板的静态label不足以表示这些变化。字幕与播放器必须使用逐turn显示名表；不要为了改字幕标签重新设计声音、改内部ID或重配相同台词。
- 输出中保留原历史显示名、事件依据与生效turn，验收时抽查“自认前一句→自认句→下一次本人发言”。字幕名改变不改原话里对他人的称呼。

## 授权编辑与未完成记录

逐字版只作自然断句和明确排版处理；任何实质新增话语或改写都标为编辑内容，供本次制作核对，不能伪装成原玩家推理。坐标、时间、计数、持物人等关键事实不因口语化而丢失。日志尚未走完就只制作已发生阶段，写明缺口。
