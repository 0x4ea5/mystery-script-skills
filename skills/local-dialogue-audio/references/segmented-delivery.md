# 分段播放、字幕与交付

本文件定义交付与验收契约。现有通用渲染器负责单稿配音、缓存和SRT；分段、动态标签、LRC及可过滤播放可由项目已验证的编排/后处理工具完成。先核实工具实际支持的功能，不把清单示意或旧播放器模板当成已经实现的筛选能力。

## 可独立播放的段落

默认按章组织独立分段MP3，同时保留必要的分章汇总和各段LRC/SRT。段落在读本/讨论转换及来源、门槛边界处切开；已有混合章须从真实turn/时间范围或分句缓存重组，不能把整章标成读本后直接删掉其中讨论。

清单至少表达以下含义，文件名与字段可沿项目约定：

| 字段 | 含义 |
| --- | --- |
| segment ID、顺序、所属章 | 稳定定位与播放次序；从实际清单计算段数 |
| `type` | 可过滤类别：`reading`为独立材料朗读，`discussion`为实际桌上发言/演绎；可扩展但需明确筛选语义 |
| 内容性质 | 自由发言、原作演绎、主持叙述、原文选段或编辑补充；与type分开 |
| 来源边界与turn范围 | 文件/版本/哈希/字符区间及起止turn；拆段不混进未获准材料 |
| MP3、LRC/SRT、时长与哈希 | 实际独立文件与局部时间轴；相对播放器入口解析 |
| 字幕显示名引用 | 每个turn对应当时生效的标签，内部speaker ID和声音不变 |

type按该段的编辑用途及实际来源确定，不能凭说话者、引用书名或文件扩展名猜测。讨论中的短原文引证仍可属于讨论；已经实际进行的原作演绎不因源于角色本就自动归为可跳过的额外朗读。

原始讨论版、旧连续版与原缓存保留，新分段版使用独立输出位置和版本标识。连续MP3是按需选项，不要求每次重造，也不把所有旧版和连续/分章文件无差别重复塞入同一个ZIP或媒体库。

制作分段与收听目录分开：缓存、审稿和并行配音可以按短片段推进，网站和离线目录按实际剧情的大阶段归组，小段仍独立下载并跨组连续播放。明确使用“阶段”“章”“小段”的真实含义，不把制作段数显示成剧本的关数或幕数，也不凭制作编号推算剧情进度；分组不改变原发言、字幕时间或文件顺序。

## “包含读本”播放器

网站/本地播放器提供“包含读本”checkbox：整合版默认选中，按完整清单播放；取消时只过滤`reading`段，保留讨论段的相对顺序与全部内容。用户选择仅讨论交付时按其要求设置初始状态。

- 在读本播放中取消勾选，转到后面第一个可播放讨论段；末尾没有可播段时正常结束。切换筛选、目录跳转和自动连播均遵守同一过滤规则，不自动回头重播旧讨论。
- 当前MP3、当前字幕和当前段标签同时更新。每个独立段的LRC/SRT以本段0秒为起点，不能把旧连续版的累计时间直接套用。
- 若页面显示累计进度，保存完整顺序与过滤顺序的映射；不要用过滤后的索引读取未过滤数组的字幕或文件。目录点击被过滤的读本须明确跳过或要求启用，不能暗中播放。
- 合并/切换不改变speaker ID、参考声音或原发言顺序；字幕继续使用该turn的历史认知标签，不在每段重置成最新终局名。
- 读取实际清单生成目录、下载项与统计。明确标注分段时长和当前选择，不把省略读本后的长度冒称完整版本长度。

至少实际验证：完整播放和取消读本时的段序、首/中/末读本过滤、混合章拆段、当前段字幕起点、自动下一段、手动跳转及显示名切换。结构检查之外，抽听切点是否截断词句、静音是否异常、音量是否突变。

## 本地成品与验收

- 默认交付分章/分段MP3、LRC/SRT、对白稿、可过滤播放器、声音配置和本次明确打包的ZIP。参考WAV/逐字文本按本次交付范围附带或给明确复用入口；不复制权重或虚拟环境。
- 核对每段脚本哈希、声音指纹、turn顺序和总数、来源覆盖、字幕标签/局部时轴。MP3做全量解码，清单文件均存在，播放器引用可解析，ZIP条目与哈希可核。可选连续版另验章节与累计字幕。
- “技术检查通过”“抽听哪些段”“是否全程逐字听校”分别报告。原话、姓名读音、漏词或重复仍需实际听校；文件存在、进程启动和自动时长检查都不等于已听完。
- 仅准备稿件或已有音频分段时完成对应范围，不为交付模板擅自启动模型。交付指出真实入口、版本、时长和未完成项。

## 远端交付只使用已授权目的地

站点发布、Drive共享和NAS复制均需要当前任务或仍有效的既有授权，不能由“做成本地音频”自动推导。先确认当前主机、权限、路径和入口可达；历史上成功过不证明本次可用。

- **站点/下载**：检查实际收听页面、清单、音频和字幕的当前链接；面向匿名收听的交付用未登录访问验证页面、直链和ZIP下载。私有交付按其权限验证，不为匿名测试擅自扩大共享范围。需要拖动定位时，验证真实音频请求的Range支持、206响应与Content-Range及实际寻址，而不只检查首页返回成功。
- **Drive**：核对目标位置、分享范围、用户可取得的下载入口和实际文件；不把创建成功或页面预览当作下载已验证。公开/匿名下载测试只针对获准的分享方式。
- **NAS/媒体库**：独立作品/版本目录，已有不同内容不覆盖；复制后回读哈希。音频标签、LRC/SRT及相对引用保全；文件到位、媒体服务扫描和客户端歌词显示分别核验。
- 上传与发布完成后关闭本次临时上传入口、会话或辅助服务，并验证关闭；不要误关应继续服务的最终播放站点。未完成上传保留可恢复状态和明确缺口。
- 密钥仅按环境授权方式使用，不写进源码、清单、日志、技能、下载URL或交付包。对外只报告可分享入口和非敏感验证结果。
