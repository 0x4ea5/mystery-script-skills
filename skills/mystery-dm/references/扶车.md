# 扶车：帮助玩家恢复方向与行动

扶车服务于玩家体验和游戏推进。先判断是推理断点，还是规则没懂、没机会参与、信息过载、情绪或节奏需要照顾，再选合适的帮助。把题答对只是可能的结果之一。

## 扶车强度

这是一组可选择的动作，不是每题必走的固定问答链。看玩家回应升级，问题解决立即收手。反复原地打转、没有新依据、明确求助或规则阻塞时介入；新反例仍在推进就继续听。

| 动作 | 何时用 | 可说的话（虚构例） | 记什么 |
| --- | --- | --- | --- |
| 聚焦问题 | 同时盘太多事 | “先只看：这句话是谁听到的？” | 当前小目标 |
| 找原句 | 知道材料在但忘了位置 | “翻一下已发的日志第二段，原话的主语是什么？” | 指向的已发来源 |
| 对照条件 | 两条信息没接起来 | “把目击时间和钟停时间放一起，会冲突吗？” | 对照两条已知条件 |
| 补一个台阶 | 中间推导缺失 | “若记录的是钟面时间，真实先后还需要确定什么？” | 实际增加的提示 |
| 局部示例 | 已知机制仍不会用 | 用已公开规则演算一个不直接给本题答案的小例子，再让玩家回做 | 用了哪些已知前提 |
| 明示补足/救援 | 原作有救援，或规则缺口确需补定义 | 明说原作救援或本桌新增条件，并允许玩家重算 | 额外前提与适用范围 |

“谁是凶手”“把全家关系盘完”往往跨度太大。改成：定位一句原文 → 确定指代 → 对比一个条件 → 排除一个候选 → 补一条板书关系。每步让玩家做，已完成部分不重问。

## 先修复输入

- 材料漏发：补发并保留原答，补发后的改答单记。不能说是玩家记性差。
- 线索在某人私本：按规则邀请分享，不替他公开私本；若他选择隐瞒，保留这一选择，不伪造分享。
- 已公开但漏听：重读实际公开原话，来源标转述；可以请当事人找原卡核实。
- OCR、图像或印刷歧义：回原图。无法确认就记待核，不为顺剧情补造一句原文。
- 本桌扣卡：检查依赖是否被拿走。必要时说明目前无法验收的缺口，或依用户已授权的变体采用明示救援。

## 提问前检查

这句话是否只用玩家此刻可知信息？是在帮他们做下一步，还是把答案藏在问句里？回答后能新增哪条信息、排除哪个候选或修改哪一笔板书？若一问跨多步就再拆。

例如（均为虚构）：玩家只知道“甲在钟响后见过乙”。不能问“既然乙是假扮的，那甲是谁？”——假扮尚未建立。可以问“甲见到的是乙本人，还是只认出了衣服？原句怎么写？”仅在已发材料确实存在可查外貌描述时采用，不能借问句凭空制造怀疑依据。

## 仍然无法推进时

先换帮助方式，不循环同一个问题：重建当前目标和已知条件，核对输入是否完整，再给更具体的一步或局部解释。向玩家提供可以实际采取的行动，并观察回应。根据本桌反馈调整强度，不把“主持说得少”设成考核目标。

非关键疑点可带着未知继续，并记清后续回查点。关键门槛优先使用原作或本桌已授权的救援/失败分支；需要新增规则才能继续时，明确缺口并取得相应决定。救援后的转场保留真实来源，既让游戏继续，也不追记成玩家自主成功。

## 如何判定帮助有效

提示后让玩家实际回应：找到原句、修正前提、提出反例或完成一次动作都算推进。仅回复“懂了”不足以认定关键机制已核验。还要看玩家是否重新清楚目标、能接上讨论、知道可做的下一步。有效讨论继续时不追求立刻通关；若仍停转，核对是不是提示错了断点，再选下一动作。

不得预设必须错误几次或必须讨论几轮；也不把别桌卡住的地方设成本桌必卡点。

## 简短记录示例（虚构）

- E018 / 公开 / 定位提示：“回看已经发的日志第二段，主语是谁？”
- 依据：日志第2段；新增前提：无；目标：区分亲眼所见与听闻。
- E019 / P2：“这里只是他听见的，不是他看见的。”
- 结果：板书把“亲眼见到”改为“听闻”；结论方式：定位提示后修正。
- 仍未知：说话者是否可靠；下一步：询问有无独立目击。
